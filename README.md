# E-commerce

Projeto Integrador, Ecommerce - 3º semestre

## Tecnologias

- Laravel
- PHP
- Blade
- Tailwind CSS
- Vite
- MySQL
- Git/GitHub

## Requisitos

- PHP 8.3+
- Composer
- Node.js
- NPM
- MySQL

## Instalação

1. Clonar o repositório
2. Instalar dependências
3. Configurar `.env`
4. Gerar chave
5. Executar migrations
6. Iniciar aplicação
